# Documentation

DASP starts from the imported [Seigyo Protocol](../upstream/seigyo/docs/seigyo/README.md). Read the [specification guide](specification/README.md) first.

Three source layers have distinct roles:

1. The frozen coding v1 bundle defines its exact baseline.
2. Current Seigyo documents explain that baseline, later approved initialization, implementation status, and proposals.
3. DASP guides identify the reusable contract and the work needed to extract it.

A section marked Proposed does not define an available operation. A draft schema does not prove server support. Existing source verification reports are historical evidence, not test results from this project.

The [initial proposal](archive/initial-proposal/README.md) is retained for history only. Its JSON-RPC messages, decimal-string revisions, and snapshot-only recovery do not define the imported protocol.
